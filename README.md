# DevelRocket AI Game Review Analysis

> 디밸로켓 「AI 기반 게임 리뷰데이터 분석 어플리케이션 개발」 6기 (2026.11.16 ~ 2026.12.28) 학습 기록 및 결과물 저장소

Steam 게임 리뷰를 직접 수집하고, LLM으로 분석한 뒤, 누구나 쓸 수 있는 웹 대시보드로 완성하는 과정을 기록합니다.

## 과정 소개

AI 모델을 직접 만드는 것이 아니라, 이미 공개된 LLM을 API로 활용해 실제 동작하는 서비스를 만드는 **AI 애플리케이션 개발** 과정입니다.
리뷰가 수만 개 쌓인 게임에서 "유저가 무엇에 만족하고 무엇에 불만인지"를 사람이 다 읽지 않고도 파악하는 것을 주제로 합니다.

| 교과목 | 차시 | 주요 내용 |
|---|---|---|
| 1. AI 입문과 개발 환경 | 1~8 | 텍스트 분석의 필요성, 임베딩 원리, Colab, Steam API 리뷰 수집, 데이터 수집 윤리 |
| 2. 데이터 전처리와 LLM 입문 | 9~15 | 텍스트 정제·정규화, 전처리 파이프라인, 샘플링, 데이터 품질 검증, LLM API 연동 |
| 3. 프롬프트 엔지니어링 | 16~24 | Few-shot·CoT, 감성 분석 심화(ABSA), 키워드·토픽 분석, 배치 처리, 에러 처리·재시도 |
| 4. 분석 심화와 서비스 설계 | 25~33 | 신뢰도 해석, 결과 검증, 시계열 트렌드, AI 편향, 인사이트 도출, 서비스 아키텍처 |
| 5. 앱 개발 기초 | 34~40 | 로컬 개발 환경, 앱 설계, SQLite DB, FastAPI 백엔드, API 설계와 보안 |
| 6. 프론트엔드와 앱 완성 | 41~44 | Streamlit 대시보드, API·프론트 연동, 최종 앱 통합 |

## 목표

- **분석 파이프라인 구축**: 수집 → 전처리 → LLM 분석 → 검증 → 집계 → 리포트까지 자동으로 이어지는 흐름 만들기
- **믿을 수 있는 결과 만들기**: AI가 스스로 매긴 신뢰도와 실제 정확도를 구분하고, 샘플 검증·일관성·분포 점검으로 품질을 수치로 확인하기
- **서비스로 완성하기**: 분석 결과를 비개발자도 클릭만으로 볼 수 있는 웹 앱(DB + API + UI)으로 만들기

## 결과물

| 단계 | 결과물 |
|---|---|
| 데이터 | 선정한 게임의 Steam 리뷰 데이터셋, 탐색 분석, 데이터 품질 리포트 |
| 전처리 | 재사용 가능한 텍스트 전처리 파이프라인 |
| LLM 분석 | 감성·Aspect·키워드·요약을 한 번에 뽑는 통합 분석, 1,000건 이상 대량 분석(체크포인트·재시도·로그) |
| 품질·인사이트 | 프롬프트 개선 전후 정확도 비교, 성능 보고서(정확도·처리 시간·비용·안정성), Executive Summary |
| 서비스 | SQLite + FastAPI + Streamlit 리뷰 분석 대시보드 (신뢰도 표시 포함) |

## 데이터·API 키 원칙

- **API 키**: Colab Secrets 또는 `.env`로만 관리하며 저장소에 올리지 않습니다. 노트북은 키가 출력된 셀이 없는지 확인한 뒤 커밋합니다.
- **데이터 수집**: Steam 공식 API(steamreviews)만 사용하고, 요청 간격을 지키며 학습·포트폴리오 목적에 필요한 만큼만 수집합니다.
- **데이터 공개 범위**: 수집한 원본 리뷰 데이터는 저장소에 공개하지 않고, 코드와 분석 결과만 공유합니다.
- **강의 자료**: 과정에서 배포된 교안과 원본 자료는 포함하지 않으며, 이 저장소에는 직접 수행한 실습 결과물만 올립니다.
- **분석 결과**: LLM 보조 분석 결과이므로 참고용이며, 한계와 검증 결과를 함께 기록합니다.
